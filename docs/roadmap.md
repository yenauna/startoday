# 학급화폐 상점 백로그

## 신비한 별 상자 (랜덤 뽑기)

상점 화폐·구매 내역·확률 설정은 차기 단계에서 구현한다. 이번 패치에서는 화폐 차감이나 추첨 API를 추가하지 않는다.

- 구매 흐름: 가격·후보·공개 확률 확인 → 구매 → 상자 흔들림 → 오픈 → 보상 공개. 잔액 검증·차감·보상 지급은 서버의 하나의 트랜잭션으로 처리하고 중복 요청 ID를 사용한다.
- CSS 연출: 상자 카드의 `transform: rotate/translate/scale`로 흔들림과 뚜껑 열기를 구현한다. 결과는 연출 이전에 서버에서 확정하며, `prefers-reduced-motion`에서는 정적 공개 화면으로 대체한다.
- 기본 가격 반비례 확률: 양수인 상품 기준 가격을 `p_i`라 하면 가중치 `w_i = 1 / p_i`, 최종 확률 `P_i = w_i / Σw_j`로 계산한다. 예: 100/200/400 가격이면 4/7, 2/7, 1/7. 가격이 0 이하이거나 숫자가 아니면 자동 확률 계산을 거부하고 교사에게 수정 안내한다.
- 교사 수동 조정: 상품별 확률을 0~100%로 입력하며 합계가 100%가 되어야 저장할 수 있다. 자동 추천값 복원 버튼과 미리보기 표를 제공한다. 수동 모드는 역가격 가중치와 섞지 않고 저장한 확률을 사용한다.
- 기록·검증: 가격/확률 설정 버전을 구매 기록에 함께 저장한다. 학생은 구매 전 적용 확률을 확인할 수 있고, 품절·비활성 상품은 계산 대상에서 제외한다. 가격 변경, 반올림 오차, 0% 항목, 중복 결제, 보상 지급 실패의 원자적 롤백을 검증한다.
