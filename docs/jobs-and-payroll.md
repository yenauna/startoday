# 월급 원장과 알바

경제 → 알바에서 공고를 등록하고 지원·선발·완료·해지를 관리합니다. 제목은 선택이며 비워 두면 카드에 제목을 표시하지 않습니다. 설명, 모집 인원, 모집 마감, 선발 방법과 선택 지원 조건을 입력합니다. 선발 방법은 가위바위보·선착순·추첨·직접 입력입니다. 직접 입력 문구는 카드와 선발 창에 그대로 표시합니다.

등록일부터 마감일까지 지원·취소할 수 있습니다. 누적 별·분야 조건은 클라이언트와 서버에서 모두 검사합니다. 학생에게 다른 학생의 지원·추첨 명단은 제공하지 않습니다. 선착순은 지원 시각 순, 추첨은 저장된 무작위 결과를 교사가 최종 확정합니다. 선발된 공고는 수정·삭제하지 않습니다.

알바 완료는 선정 학생마다 알바 분야 칭찬을 한 번 기록합니다. 활동 시작일 제한은 없습니다. 알바 해지는 기록 없이 종료합니다. 완료와 해지는 서로 전환할 수 없습니다. 고정된 기록 ID와 공고 버전으로 중복 처리와 동시 변경을 막습니다.

알바는 학생별 직업 월급 설정을 자동 변경하지 않습니다. 기존 월급 화면의 수동 직업 월급 입력은 유지합니다. 기존 공고와 과거 지급·활동 기록을 삭제하거나 소급 지급하지 않습니다. 예전 공고를 수정 저장하면 알바 필드로 저장합니다.

학생 잔액은 경제 거래 원장만 합산합니다. 완료 칭찬은 월급 정산에 포함되며 즉시 포인트가 생기지 않습니다. 지급 당일 뒤늦게 완료한 칭찬도 다음 정산에서 한 번 반영합니다.

이번 변경은 `schema.sql`의 공고 검증·저장·완료·해지 처리를 갱신합니다. 운영 DB에는 머지 후 최신 SQL을 별도 적용해야 합니다.
