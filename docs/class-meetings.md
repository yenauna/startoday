# 학급회의 운영

최신 `schema.sql` 전체를 서버 SQL 관리 화면에 적용하면 학급회의 전용 테이블과 인증 함수가 추가됩니다. 기존 경제·기록 자료는 유지됩니다.

## 임원과 안건

교사는 학급회의 → 설정에서 회장·부회장을 여러 명 지정할 수 있습니다. 같은 학생이 두 직책을 맡아도 검토 인원은 한 명으로 셉니다. 임원을 바꾸면 대기 안건의 검토 동의를 초기화해 새 임원이 다시 살펴보게 합니다.

학생 안건은 항상 대기로 등록됩니다. 회장이 직접 제안해도 먼저 대기로 저장하며 필수 확인 모달을 표시합니다. 회장은 진행·논의 보류·삭제를 고를 수 있습니다. 진행을 고르면 본인의 검토 동의를 남깁니다. 부회장도 자기 계정에서 검토에 동의할 수 있습니다. 회장의 확인과 전체 임원 중 절반을 넘는 동의가 모이면 투표를 엽니다. 이 검토는 안건에 대한 찬성·반대 투표와 별개입니다. 교사는 직접 안건을 열거나 대기 안건을 승인·삭제할 수 있습니다.

찬반은 찬성·반대 중 한 개를 고릅니다. 직접 입력 유형은 선택지를 계속 추가할 수 있고 최대 선택 개수를 지정합니다. 선택지 개수에 별도 고정 상한은 없으며 입력 전체 용량과 항목 길이는 서버에서 검증합니다. 교사와 회장은 대기 안건의 **투표 설정**에서 선택지와 최대 선택 개수를 확정할 수 있습니다. 설정을 바꾸면 이전 검토 동의를 초기화합니다. 열린 투표는 선택지를 바꾸지 않습니다.

## 비밀투표와 마감

투표를 열 때 재적 학생 명단을 확정합니다. 진행 중 학생 응답에는 참여 인원과 본인 제출 여부만 포함하고, 선택지별 득표 수와 다른 사람의 응답은 포함하지 않습니다. 교사는 선택지별 실시간 합계를 보지만 개별 학생과 선택지를 연결하는 원자료는 받지 않습니다.

학생은 한 번만 제출할 수 있습니다. 마감 시각 도래, 재적 전원 참여, 교사 수동 마감 중 하나로 종료합니다. 마감 시각을 비우면 전원 참여 또는 교사 마감으로 종료합니다. 시간은 한국 시간으로 입력·표시합니다. 전학 등으로 투표 개시 이후 재적이 달라졌다면 교사가 수동으로 마감할 수 있습니다.

화면에 들어갈 때와 열어 둔 동안 주기적으로 새 자료를 확인합니다. 투표 선택지는 새로고침해도 유지하고, 작성 중인 모달이나 임원 설정은 자동 갱신으로 덮어쓰지 않습니다. 제출·권한·마감 판단은 서버가 다시 확인합니다.

## 회의록

교사와 현재 지정된 부회장만 작성·수정할 수 있습니다. 진행자·기록자는 임원 이름 버튼으로 넣거나 직접 여러 명을 입력합니다. 전체 인원은 현재 재적을 기본값으로 사용하며 수정할 수 있습니다.

- 참여 인원 = 전체 인원 − 결석 인원 − 불참 인원
- 결석은 학교 결석, 불참은 출석했으나 회의에 참석하지 않은 인원입니다.
- 전체 인원이 1명 이상이고 참여 인원 × 4 ≥ 전체 인원 × 3이면 회의 성립입니다.
- 결석+불참이 전체 인원보다 크거나 정수가 아닌 입력은 저장할 수 없습니다.

진행 중·마감 투표를 여러 개 연결하면 제목·상태·결과 카드를 함께 저장합니다. 학생에게는 연결 카드에서도 진행 중 득표 수를 숨깁니다. 해당 투표가 마감되면 최종 결과를 보여 줍니다. 수정 버전이 달라지면 덮어쓰지 않고 새로고침을 안내합니다.

## 시간표

달력 수업 칩은 안쪽 버튼만 드래그를 소유합니다. 카드 여백을 눌러도 교시 편집을 엽니다. 빈 날짜로 이동하면 원래 교시를 유지하고, 다른 수업 교시로 옮기면 두 수업을 교체합니다.

수업 사이의 빈 교시는 `+ 수업 등록`으로 표시합니다. 마지막 수업 뒤의 빈 교시는 접고 `+ 교시 추가`로 펼칩니다. 수업이 없는 날에도 첫 교시는 등록할 수 있으며 교시와 연결된 행사는 숨기지 않습니다.
