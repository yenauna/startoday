# 알림장

교사 메뉴의 **알림장**에서 날짜별로 작성합니다. 학생 개인 화면과 학생 로그인 응답에는 알림장 자료를 제공하지 않습니다.

- 알림장 날짜는 작성 대상 날짜입니다. 달력에서 같은 날 항목을 고르면 오늘 한 일, 이후 날짜 항목을 고르면 미래 일정에 담습니다. 이전 날짜 항목은 확인만 가능합니다.
- 일정, 일반 과제, 메모1·메모2가 있는 수업을 선택할 수 있습니다. 장기과제·루틴·교사 전용 메모3은 포함하지 않습니다.
- 오늘 한 일은 화살표로 순서를 바꾸고 문구를 고칠 수 있습니다. 미래 일정은 날짜순으로 정렬하고 `[월.일.요일]` 말머리를 자동으로 붙입니다.
- 과제의 미제출자 토글은 그 과제가 발생한 날짜의 대상 학생 중 `진행중`·`안함`을 표시합니다. 출결 제외·삭제 학생과 완료·늦게완료·면제 학생은 제외합니다. 저장할 때의 결과가 완성 텍스트에 보존됩니다.
- 생활 문구는 요청된 기본 문구를 포함한 200개 풀에서 선택합니다. 기념일 당일 또는 1~2일 이내의 직전 평일을 우선 추천하고, 그 외에는 해당 계절과 일반 문구에서 날짜를 기준으로 일정하게 순환합니다. 교사가 문구를 직접 고치거나 다른 추천으로 바꿀 수 있습니다.
- 저장된 날짜를 선택해 다시 수정하거나 삭제할 수 있습니다. 저장 전 다른 날짜를 불러오면 변경 내용을 버릴지 확인합니다. 삭제는 표식을 남기며 같은 날짜를 다시 저장하면 복구됩니다.

교실화면 **알림장** 버튼은 오늘 저장된 완성 텍스트를 우선 표시합니다. 없으면 오늘의 생활 문구 기본 초안을 표시합니다. 크게 보기 중에는 배경 앱을 숨겨 점수·다른 탭이 보이지 않으며 닫기·Esc로 돌아와도 교실화면 잠금이 유지됩니다.

`schema.sql`에는 기존 교사 동기화 경로를 사용하는 `startoday_notices` 테이블과 날짜·항목 검증을 추가했습니다. 날짜당 `notice:YYYY-MM-DD` ID 하나를 사용합니다. 교사 스냅샷·백업·수정 버전 검증에 포함되며 RLS는 소유 교사만 읽도록 제한하고 직접 쓰기는 허용하지 않습니다. 운영 DB에는 머지 후 최신 SQL 전체를 별도로 적용해야 합니다.
