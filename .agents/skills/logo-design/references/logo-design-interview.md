# Logo Design Interview

Ask a single focused batch after the user has reviewed and confirmed the pre-design Logo Direction Guidelines. Read the files first and skip questions that already have clear, approved answers. Aim for at least five or six distinct answered decisions, not six repeated questions.

## Six core decisions

1. **Logo route:** Should the identity be a symbol plus name, name-only wordmark, monogram, emblem, or a combination? Which route from the approved direction feels right? If unsure, present two distinct route options and their trade-off.
2. **Meaning anchor:** What specific product, action, name meaning, place, origin, or approved story should the logo refer to? Which references, symbols, or readings must be avoided? Never invent cultural or factual meaning.
3. **Visual behavior:** Should the approved territory feel geometric, organic, typographic, hand-drawn, architectural, editorial, or another defined behavior? Ask about the principle, not a generic moodword list.
4. **Exact name and script hierarchy:** Confirm the exact Arabic/Latin spelling, language order, transliteration if approved, tagline treatment, punctuation, diacritics, and whether one or both scripts belong in the mark. Reuse the approved spelling verbatim.
5. **Primary use and constraints:** Where must the logo work first—app/avatar, storefront/signage, packaging, documents, embroidery, stamp, or another confirmed place? Ask for the smallest expected use and any print/process limits that materially affect detail.
6. **Color and contrast behavior:** Use which already-approved palette colors and roles? Does the user need approved one-color, reverse, or light/dark forms? If color values are not approved, pause for the identity stage.

## Useful follow-ups when they affect the design

- Name two or three direct competitors whose visual territory must be avoided. Do not ask for competitor copying.
- What is the current brand tier and audience expectation, in operational terms? Avoid interpreting “premium” as a color or effect.
- Should a descriptor/tagline be part of the primary lockup, a secondary lockup, or kept separate?
- Is there a visual feature in a previous concept that must stay or must go?
- Which image model/tool will receive the prompt, if its constraints change the prompt structure?

## Confirmation before prompt

Summarize: chosen route, central concept sentence, shape logic, approved spelling/script, exact palette roles, intended contexts, exclusions, files to attach, and one or two open production risks. Ask the user to confirm or correct this summary before drafting if the project's stage requires approval.
