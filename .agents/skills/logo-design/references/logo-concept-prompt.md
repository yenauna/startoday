# Logo Concept Prompt Framework

Create one focused prompt for one direction. If presenting multiple routes, keep them as separately labeled prompt blocks so the image tool does not merge incompatible ideas.

## Required prompt fields

1. **Task and status:** early logo concept exploration; not a final editable/trademark-cleared master.
2. **Brand and exact approved spelling:** include script, directionality, language order, diacritics, and tagline policy.
3. **Approved inputs:** brand identity file and exact filenames of user-supplied brand assets to attach. State each asset's role: preserve, inform palette, or inform context. Do not ask the user to attach competitor/reference artwork by default; translate researched precedents into abstract methods and cite direct URLs in the research record. Use a reference image only if the user supplied or authorized it and its role cannot be met safely through a written method.
4. **Audience and brief:** only verified category, market, user, offer, and personality details that affect the mark.
5. **Single idea:** one sentence explaining the mark's concept in terms of the brand, followed by the elements that express it.
6. **Form logic:** silhouette, geometry/stroke behavior, negative space, proportion, corner/terminal behavior, detail level, and relationship between mark and wordmark.
7. **Color:** exact approved hex values and roles, approved background, and whether the test is color or monochrome. Never make up a palette.
8. **Composition:** the main centered logo, relevant light/dark or scale tests, empty margins, aspect ratio, canvas/background, and intended display.
9. **Exclusions:** unrelated literal clip-art, stock icons, invented text, 3D mockups, gradients/effects unless approved, extra colors, false symbolism, competitor resemblance, and unnecessary supporting marks.
10. **Text reliability:** require exact spelling only if the tool can render it; otherwise generate the symbol with a clean, correctly proportioned blank wordmark zone for manual setting in a vector tool.
11. **Quality check:** a recognizable one-color silhouette, small-size reading, balance, contrast, script proofing, and comparison against reference originality boundaries.

Build a clear, distinctive silhouette with **[geometry/stroke/negative-space/proportion constraints]**, suitable for **[confirmed primary use]** at **[smallest known size or practical test]**. Use only **[HEX — role]**, **[HEX — role]**, on **[approved background HEX]**. The exact approved name is **[copy exact spelling]** in **[script/language hierarchy]**; preserve right-to-left Arabic behavior and do not alter letters, add diacritics, translate, or invent a tagline. Attach **[exact user-supplied brand filename]** as **[its precise role]**. Use any researched references only through these abstract methods: **[general transferable principles]**; do not copy a mark, geometry, arrangement, palette, typeface, or signature device. Delete the brackets and resolve every decision before handing the prompt to the user.
