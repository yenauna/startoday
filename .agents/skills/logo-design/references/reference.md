# Reference Instructions — `logo-design`

Read this file, `../../shared-references/research-reference-standard.md`, the approved Logo Direction Guidelines, `logo-design-interview.md`, and `logo-concept-prompt.md` before drafting. This skill is for a new symbol/combination/emblem/monogram route; an approved name-only route belongs to `../../logo-text/SKILL.md`.

**Approval gate:** Begin only after the user has approved the pre-design Logo Direction Guide. Ask the 5–6 unanswered pivotal logo decisions below, then wait for confirmation of the chosen mark route and concept sentence before researching that route or drafting its prompt. Reuse facts already answered in the brand interview.

## Interview: decisions that steer the mark

After the user has approved the pre-design guide, ask 5–6 **unanswered pivotal decisions** in one batch. Reuse identity answers and do not repeat them:

1. Which logo route (symbol + name, emblem, monogram, or combination) and what job should the mark perform?
2. What real name/product/story/behavior may inform the concept, and which associations are forbidden?
3. What is the exact approved name/script/language order? Is lettering part of the mark or set separately?
4. Which visual behavior from the approved guide is preferred, and what observable form traits should express it?
5. Where and at what smallest size/production process must it work first?
6. Which already-approved palette variant(s) and background are required? If palette is missing, route back to `brand-identity`.

Ask about competitors, an approved tagline, or output-tool constraints only if they will change the route. If a single clarification settles several issues, ask it rather than a list of minor preferences. Confirm the selected route and concept sentence before writing.

## Reference study for concept work

Inspect at least five actual logo projects, chosen for the selected route, sector, writing system and use case. Reuse the visually inspected logo-guideline sources when they truly show the mark; supplement with distinct cases if not. Compare concept-to-form translation, silhouette, negative space, stroke/edge behavior, symmetry, scale, mark/wordmark hierarchy, exact script rendering and variants. For each, record the source's brief separately from what you infer about the form. Do not use another logo as an image-generation target or copy its visual signature.

## Route branches and prompt logic

- **Symbol-only** → ask whether the wordmark is omitted from the master or simply a separate lockup; preserve the approved brand name elsewhere.
- **Combination mark** → define which piece leads and the approved horizontal/stacked/small arrangement; don't generate unapproved variants automatically.
- **Monogram/emblem** → use only real initials/name components; decide enclosed/uncontained form, outline, and minimum visible details from the use case.
- **Abstract mark** → anchor to a specific design principle or approved concept; set silhouette and structural constraints. Do not write only “abstract premium icon.”
- **Wordmark only** → stop and route to `../../logo-text/SKILL.md`; do not append an icon to satisfy this skill.
- **Existing mark edit** → stop and route to `../../logo-prompting/SKILL.md`; preserve the entire current artwork and specify one alteration.
- **Research points to multiple distinct routes** → present no more than two alternatives with different jobs; wait for the user to choose before prompting.

The final prompt includes the approved brief and exact asset filenames/roles; one concept; meaning anchor; form/silhouette, negative space, proportion and stroke logic; exact HEX roles/background; text/script fallback; image canvas and centered flat presentation; minimum-size and monochrome checks; specific exclusions; and originality boundaries. Separate the logo exploration from mockup photography. Label any raster result as concept artwork, not vector master or clearance.
