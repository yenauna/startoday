# Page Structure & Project Folder Convention

## Project folder (shared across all skills in this collection)

```
/project-name/
  AGENTS.md (or brief.md)   → the locked brand brief from ../brand-identity
  /assets/
    /logo/        → approved logo file(s) from ../logo-prompting
    /mockups/     → approved mockup images from ../mockup-prompting
    /canva/       → any manually-made design elements, if used
  /output/
    /prompts/     → approved, requested prompt packs
    brand-presentation.html   → this skill's deliverable
    banners/                  → ../banner-design's output, if generated
```

## Required sections, in this order (single continuous scroll — never separate pages/tabs)

1. **Cover / Intro** — brand name + a short tagline, full-bleed, the first thing seen.
2. **Logo** — the logo at multiple sizes, shown on both light and dark backgrounds, plus an icon/monogram version if one exists.
3. **Color Palette** — every locked color with its hex code, a name, and its role (primary / secondary / accent / background) — pulled exactly from the brief, never re-derived.
4. **Typography** — the chosen font(s), shown with heading and body examples at real sizes.
5. **Logo Usage** — only confirmed or measured rules for clear space, minimum size, and misuse. Omit numeric rules that are unknown; do not guess.
6. **Mockups / Applications** — only the approved mockups from `../mockup-prompting`, shown large, in the order a customer would naturally encounter them (e.g. logo → packaging → storefront or app icon → onboarding → dashboard, not alphabetical).

## Why this order

It establishes the mark, explains the system behind it, and then shows the approved applications as proof. Keep the single-scroll structure; adjust emphasis and pacing for the brand rather than copying a reference page.

## Content and evidence rules

- Keep this order as a default, but omit a section when the brand has no approved content for it. Ask if a requested section needs a missing asset or value.
- Source every displayed name, claim, font, hex value, and logo rule from the locked brief or approved project files. An inspiration image is not a source of client facts.
- Use captions only when they explain a real design decision. Do not write generic marketing copy to fill empty space.
- Alt text should identify what an informative image shows, not repeat nearby decorative copy.
- Build the sequence to answer: What is the idea? What are the core assets? How does the system behave? Where will the audience encounter it?
