# Logo Guideline Structure

Use the sections that fit the mode. Do not fill a section with invented rules.

## A. Pre-design Logo Direction Guidelines

This is used before a logo exists.

1. **Decision basis** — approved brand identity file, user-approved facts, supplied assets, and open decisions.
2. **Logo job** — the recognition or communication task the mark needs to perform; do not repeat generic brand adjectives.
3. **Design territory** — one recommended route (symbol, wordmark, monogram, emblem, or combination) and, only if genuinely competitive, one alternative.
4. **Meaning anchors** — concrete source ideas from the real offer/name/story; distinguish literal, metaphorical, and abstract routes.
5. **Shape and silhouette principles** — visual complexity, mass, geometry/organic behavior, negative-space role, and intended scale, without describing a competitor's drawing.
6. **Script and lettering behavior** — exact approved spelling, Arabic/Latin hierarchy, reading direction, punctuation/diacritics, and what requires manual typography.
7. **Color behavior** — only approved hex values and their identity roles; state one-color, reverse, and background questions explicitly.
8. **Application checks** — avatar/favicon, packaging/signage, print/embroidery, or other confirmed use cases. Do not add irrelevant mockups.
9. **Avoid list** — category clichés, unwanted meanings, competitor resemblance risks, visual tropes unsupported by the brief.
10. **Reference evidence** — at least five distinct source pages; visually inspected sources separated from text-only or blocked sources.
11. **Approval gate** — ask the user to confirm the recommended territory before `logo-design`.

## B. Post-design Logo Use Guidelines

Use only after the user approves a real logo asset.

1. Master asset, filename, format, color profile, and approved script/spelling.
2. Logo anatomy and variants that are actually supplied or expressly approved.
3. Construction/grid only if it is accurate, useful, and measured from the master vector.
4. Clear space and minimum reproduction size only when owner-approved or verifiably measured; name the testing medium and threshold.
5. Exact approved color variants, contrast, backgrounds, and reverse usage.
6. Wordmark/symbol relationship, alignment, proportions, and lockup behavior.
7. Small-scale reductions and one-color reproduction tests.
8. Correct and incorrect examples: distortion, recoloring, unapproved outlines/shadows, rearrangement, cropping, clutter, and use of unapproved files.
9. Co-branding or placement rules only when the brand has confirmed them.
10. Version/date, owner, source file, and approval status.

## Copy-ready visual-guideline-board prompt skeleton

Only use in Mode B, after confirming the supplied master file. Replace brackets with verified values.

> Create a clean, editable logo usage-guidelines board for **[brand]** using the attached approved logo master **[exact filename]** as the only logo artwork. Preserve its geometry, proportions, spelling, kerning, and colors exactly; do not redraw, stylize, regenerate, or substitute the mark. Use the approved palette only: **[HEX — role]**. Include only verified content: [approved variants], [measured/approved clear-space rule], [measured/approved minimum size and test medium], [approved backgrounds], and [specific misuse examples]. Show the actual file at readable scale with clear labels and generous spacing. Keep measurements and typography fully editable and legible. If a value is unknown, omit that rule and label it “needs owner approval” rather than inventing a number. Deliver [page size / aspect ratio / format] with clean vector-like diagrams, accessible contrast, a source-file/version footer, and a final check that every rule matches the supplied master. Exclude decorative effects, fabricated technical grids, new logo variants, extra colors, invented copy, and any reference-project artwork.
