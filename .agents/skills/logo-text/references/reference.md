# Reference Instructions — `logo-text`

Read this file, `../../shared-references/research-reference-standard.md`, `wordmark-interview.md`, `wordmark-prompt.md`, the approved Logo Direction Guidelines, and the exact name in the locked brief before acting. This skill is only for a logo whose primary and complete mark is **text**.

**Approval gate:** Audit the exact user-provided spelling and assets first. Confirm whether the requested route is truly text-only, ask only missing high-impact lettering decisions, and wait for approval of script, name, route, and research scope before searching wordmark examples or drafting a prompt.

## Stop the route from drifting

At the start, confirm whether the user wants a text-only wordmark or a separate symbol plus name. If text-only is approved, the prompt must not contain an icon, badge, monogram symbol, emblem, illustration, or decorative frame. If the user wants a symbol with text, return to `../../logo-design/SKILL.md`. If the user wants an existing wordmark corrected, use `../../logo-prompting/SKILL.md`.

## Ask high-impact lettering questions

Ask only unresolved decisions: exact spelling/scripts and language order; whether tagline is excluded; typographic character; custom lettering versus an approved/licensed typeface starting point; distinctive letter/glyph behavior; weight, width, contrast, terminals and rhythm; Arabic RTL shaping/ligature behavior; bilingual lockup; main use and smallest size; approved colors. Confirm text by reproducing it exactly to the user. Never ask what can be determined from an approved file.

## Research actual lettering

Inspect at least five distinct wordmark/logotype images, including Arabic references whenever Arabic is part of the logo. Search real client/official cases first, then credited designer portfolios. Analyze visible letterforms at normal and small scale: script skeleton, joins, counters, diacritics, baseline, spacing/kerning, rhythm, terminal treatment, stroke contrast, width, negative space, Arabic/Latin weight matching and lockup hierarchy. Mark exact typeface names/identity as unknown unless source metadata confirms them. Prefer transferable observations (e.g. rhythm or weight balance) over named style imitation.

## Script-specific branches

- **Arabic-only** → correct RTL order, connected shaping, valid joins/ligatures, approved diacritics, and proofing by a fluent reviewer; never accept isolated pseudo-Arabic glyphs.
- **Latin-only** → preserve accents, capitalization, punctuation, and exact spelling; examine letter spacing and trademark-like visual similarity.
- **Arabic + Latin** → confirm which script leads, reading order, stacked/side-by-side choice, relative optical weight and use contexts; do not assume translation or transliteration.
- **Exact generator lettering unreliable** → request a typographic layout/letterform direction with a clear empty name area, then manual vector typesetting. Do not ask for fake text.
- **Unknown name meaning/pronunciation** → ask the owner; do not invent etymology to justify a letterform.

## Research-to-prompt fields

Map each recommendation to an observed script/lettering method and to the brand brief. Specify exact name, script, direction, typography principle, letterform behaviors, palette HEX and roles, clean layout, contrast, scale, exclusions, source asset roles, manual-typing fallback, and quality checks. No reference artwork should be attached as an imitation target. If five actual lettering images are not accessible, label the recommendation provisional and add the Agent Reach note required by the shared standard.
