# Wordmark Interview

Ask one concise batch after reviewing the approved brief and logo-direction research. Skip answered items. Aim to establish at least five or six separate design decisions before writing a prompt.

## Core decisions

1. **Name-only route:** Should the exact brand name stand alone, or may a separate symbol appear? Should any tagline stay outside the wordmark?
2. **Script and exact spelling:** Which exact Arabic/Latin spelling is approved? Which language is primary? What order, transliteration, diacritics, punctuation, spacing, or legal suffix is required?
3. **Typographic character:** Should the wordmark be built from geometric, humanist, calligraphic, editorial, industrial, soft, or another concrete typographic behavior? Which choice is supported by the brand direction?
4. **Custom-lettering level:** Should the prompt explore a custom drawn wordmark, refined existing lettering, or a licensed typeface as a starting point? Which letters or glyph joins must become distinctive?
5. **Letter construction:** What should happen to stroke weight/contrast, terminals, counters, bowls, ligatures, proportions, width, baseline, and spacing? Ask only about details the user can meaningfully decide.
6. **Bilingual relationship:** If two scripts are needed, should they be matched in visual weight and width, stacked or side-by-side, and on which applications? Confirm whether both versions are primary or one is a secondary lockup.
7. **Palette and output use:** Which approved HEX colors and roles? Where must it read first, and at what smallest size or reproduction process?

## Follow-ups if still decision-critical

- Which competitors or familiar wordmarks must the result avoid resembling?
- Should the wordmark feel static and stable or expressive and movement-led?
- Do existing approved typefaces or licenses need to be respected?
- What tool will receive the prompt, and can it render Arabic/Latin typography reliably?

## Final text lock

Before writing the prompt, quote the approved name exactly for confirmation, including script and direction. Do not create prompts while text is still disputed.
