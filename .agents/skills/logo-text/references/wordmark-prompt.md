# Wordmark Prompt Framework

## Required prompt details

- Exact name in every approved script, copied character for character.
- Explicit text-only rule: no pictorial mark, badge, icon, or invented ornament.
- Intended audience, category, market, and approved logo direction.
- Letterform principle, custom-lettering approach, weight/width/contrast, terminals, counters, baseline, and spacing/rhythm.
- Arabic RTL and correct shaping/joins; bilingual hierarchy, order, scale, and lockup if approved.
- Exact approved colors and roles; background value; no additional palette.
- Clean composition on a neutral field, output ratio, useful margin, and scale/readability variants if requested.
- Tool limitations and clean blank area/manual typesetting fallback.
- Exclusions and quality checks for spelling, glyph joins, legibility, distinctiveness, and fidelity to the brief.

## Copy-ready prompt skeleton

> Create an original **text-only wordmark** for **[brand]**, using the approved brand brief **[exact filename]**. The complete logo is the exact name **“[paste approved brand spelling]”** in **[script/language order]**; preserve every character, punctuation mark, spacing, and diacritic exactly. If Arabic is included, set the text in correct right-to-left order with connected, correctly shaped glyphs and approved ligatures; do not reverse or separate letters. Do not add an icon, monogram symbol, badge, illustration, frame, decorative underline, invented tagline, or extra wording. Develop custom lettering guided by **[approved typographic direction]**: **[specific stroke/terminal/counter/width/contrast/spacing behavior]**. Make any distinctive letter treatment support readability rather than obscure the name. If bilingual, use the approved order and relationship: **[stacked/side-by-side/primary-secondary]** with optically balanced scale and weight, not automatically identical widths. Use only **[HEX — role]**, **[HEX — role]**, on **[background HEX]**. Show one clean flat wordmark at **[ratio/size]**, with generous clear space and no perspective or photorealistic mockup. Use the attached **[brief/type sample/logo file]** only as **[specific role]**; do not copy reference letterforms or imitate competitor wordmarks. Exclude **[brand-specific avoid list]**, font-preview text, extra glyphs, false Arabic lettering, altered spelling, clip-art, unapproved effects, and unsupported claims. Check exact spelling, RTL shaping, joins, kerning, counters, rhythm, readability at **[smallest intended size]**, one-color clarity, and fit to the approved audience/market. If exact lettering cannot be rendered, create a clean typographic layout study with an empty, correctly proportioned wordmark area for manual vector typesetting; do not output pseudo-text.

## Human proofing note

The user must inspect every character at full size. Generated lettering is not the approved master. Refine and rebuild final Arabic/Latin lettering in a vector tool with a designer and verify font licensing before production.
