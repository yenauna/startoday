# Brand Consistency Checklist

## Visual Consistency

### Logo
- [ ] Correct logo version used
- [ ] Approved clear-space rule maintained, if one exists
- [ ] Approved colors only
- [ ] Legible at all sizes
- [ ] No unauthorized modifications
- [ ] Correct approved file/version is traceable to the project brief

### Colors
- [ ] Only brand palette colors
- [ ] Consistent color application
- [ ] Proper contrast for accessibility
- [ ] Color ratios maintained

### Typography
- [ ] Brand fonts used
- [ ] Correct weights/styles
- [ ] Proper hierarchy
- [ ] Consistent formatting
- [ ] Script direction, spelling, diacritics, and fallbacks are correct for the language

### Imagery
- [ ] Matches brand style
- [ ] Consistent editing/filters
- [ ] Appropriate subjects
- [ ] Quality standards met

## Voice Consistency

### Tone
- [ ] Matches brand personality
- [ ] Appropriate for context
- [ ] Consistent across channels
- [ ] No conflicting messages

### Language
- [ ] Brand terminology used
- [ ] Consistent capitalization
- [ ] Proper abbreviations
- [ ] Jargon level appropriate

### Messaging
- [ ] Aligns with key messages
- [ ] Value prop clear
- [ ] Differentiators highlighted
- [ ] CTAs consistent
- [ ] Claims match approved evidence and are labeled correctly for their channel

## Channel Audit

### Website
- [ ] Homepage
- [ ] Product pages
- [ ] Blog/content
- [ ] Footer/navigation

### Social Media
- [ ] Profile images
- [ ] Cover images
- [ ] Bio/about sections
- [ ] Post templates

### Email
- [ ] Header/footer
- [ ] Templates
- [ ] Signatures
- [ ] Automated messages

### Collateral
- [ ] Presentations
- [ ] One-pagers
- [ ] Business cards
- [ ] Promotional materials

## Common Issues

| Issue | Fix |
|-------|-----|
| Outdated logo | Replace with current version |
| Off-brand colors | Update to palette |
| Wrong font | Replace with brand font |
| Inconsistent voice | Apply style guide |
| Mixed messaging | Align to framework |

## Audit Cadence

Set a review trigger with the brand owner based on the release cycle, campaign frequency, or a material identity change. Do not assume the same calendar schedule for every team. Record the last review date, scope, findings, and owner for the next pass.

## Reference and evidence check

- [ ] Inspiration sources are credited internally and no distinctive work was copied
- [ ] Draft/concept outputs are not confused with approved brand assets
- [ ] Platform or printer requirements were checked from current official/vendor documentation
- [ ] Every unconfirmed rule is labeled as a recommendation or open decision
