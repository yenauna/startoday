## Clear space and minimum size

- Use the rule explicitly supplied in the approved logo package when one exists.
- If no clear-space rule is supplied, measure a provisional margin from the approved artwork, document the method and version, and obtain approval before publishing it as a standard.
- Determine minimum size by testing the approved asset at the actual required screen and print sizes. Record the smallest size at which every essential element remains legible. Do not reuse a universal pixel/mm value for all logos.
- Check icon-only and full lockup separately. A wordmark, Arabic diacritics, small tagline, or thin detail may fail at different sizes.

## Background and contrast

Use only approved logo color variants on backgrounds listed in the brand brief. Check readability against the actual background or image. A light/dark version should be created as an approved source file, not improvised by changing the mark's color.

For photography, place the mark on an approved quiet area or add an approved support shape. Do not add a new outline, shadow, glow, or panel without approval.

## Correct use

- Preserve the approved file's proportions, spacing, geometry, colors, and internal relationships.
- Use the right lockup for the available space and actual customer context.
- Keep the mark clear of surrounding text and image detail according to the confirmed spacing rule.
- Preserve every character, diacritic, and script direction in the approved wordmark.
- Use vector artwork where the output requires scaling, if an approved vector asset exists.

## Incorrect use

- Stretching, squeezing, rotating, skewing, or cropping the mark
- Recoloring, applying unapproved effects, changing opacity, or adding a stroke
- Re-typesetting or translating an approved wordmark without an approved master
- Rearranging combined elements or changing their proportions
- Placing a low-contrast version on a busy image
- Using an AI-generated redraw when the approved logo file is available

## Co-branding

Co-branding rules depend on the relationship and contract. Confirm partner asset variants, visual hierarchy, spacing, legal requirements, and placement with the brand owner before specifying them. Do not assume every partner mark should have equal visual weight or use the same divider layout.

## Output formats and platform sizes

Use supplied master formats. SVG is often appropriate for supported digital contexts and vector PDF for print, but confirm with the receiving system or printer. PNG may be needed for compatibility; export at the required size and preserve transparency when needed.

For social/profile, web, document, or campaign use, verify current platform/vendor specifications at delivery time. Record the source URL and check date. Do not embed a stale dimension table as permanent logo policy.

## Final check

- [ ] Correct approved version and file path
- [ ] Correct background variant and sufficient contrast
- [ ] Proportions, spelling, diacritics, and clear space preserved
- [ ] Size tested in the real use case
- [ ] No unapproved transformation or effect
- [ ] Platform or print requirement checked from its current official source
