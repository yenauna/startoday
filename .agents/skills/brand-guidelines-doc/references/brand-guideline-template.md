# Brand Guideline Structure

Use `../templates/brand-guidelines-starter.md` as the editable document. This file explains how to tailor the structure and must not be treated as a source of brand defaults.

## Choose the scope

- **One-topic request:** write only the requested section (for example, voice, logo rules, or palette specs) and include its source/status.
- **Core guide:** include the brand foundation, visual identity, voice, real touchpoint rules, and review checklist.
- **Full handoff:** add asset paths, channel-specific use, ownership, and change history where the user has supplied the information.

## Recommended order

1. Document control and source-of-truth note
2. Quick reference
3. Brand foundation: audience, market, offer, promise, proof, differentiation
4. Visual identity: logo, color, typography/scripts, graphic language, imagery
5. Voice and approved messaging
6. Real touchpoint rules
7. Asset locations and naming
8. Quality review and approval status
9. Change history and open decisions

## Status labels

Use these labels consistently:

- **Approved** — explicitly locked by the owner or approved source file.
- **Measured** — derived from a named, versioned asset and checked by the owner when needed.
- **Recommended** — a proposal that has not yet been approved.
- **Open** — missing, conflicting, or not yet decided; never present as policy.

## Avoid false precision

Do not fill the template with sample hex values, default fonts, generic color ratios, arbitrary minimum sizes, assumed clear space, placeholder performance claims, or made-up legal requirements. If an exact number is required, cite its source, measurement method, and relevant file version.
