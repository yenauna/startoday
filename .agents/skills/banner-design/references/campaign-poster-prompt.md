# Campaign Poster and Key Visual Prompt

Use this reference for product posters, launch posters, campaign key visuals, event posters, and story-led brand posters. Read the brief and run the shared intake before writing a prompt. Ask which poster type, where it will appear, which copy is approved, and whether it is a digital visual or print design. Do not guess campaign claims, event facts, dimensions, or offers.

## Choose the poster's job first

Select one primary job:

- **Product poster:** make one approved product/feature the focal point and support recognition or consideration.
- **Launch poster:** announce a confirmed launch, date, place, and action.
- **Campaign key visual:** establish a reusable visual idea that can scale into a series of placements.
- **Story poster:** translate an approved founder/product/place story into an image without adding facts.
- **Event poster:** prioritize verified event name, date, time, venue, and ticket/action details.

Do not mix multiple jobs or CTAs unless the brief says they are required.

## Ready-to-paste image prompt pattern

```text
Create one [product / launch / campaign key visual / story / event] poster concept for [brand]. Use the attached approved brief, actual logo file, and selected brand assets as the source of truth.

Communication goal: [one approved goal].
Audience and market: [confirmed audience, country/region, language/script/dialect].
Approved message: [exact headline, support line, CTA, and required legal/date details], or leave clearly defined blank space for manual typesetting. Do not invent or paraphrase approved copy.
Product/story evidence: [specific product, feature, founder story, ingredient, or place that the user confirmed]. Do not add unsupported claims or cultural symbols.
Visual concept: [one concrete image idea tied to the confirmed message/story].
Composition: [one focal point, reading order, logo area, copy area, negative space, depth, and crop behavior].
Brand treatment: [approved art direction and typography behavior]. Use only these exact palette colors and roles: [#HEX role, #HEX role].
Image craft: [photography / illustration / 3D / collage], subject/material, camera distance, lighting, contrast, surface detail, and background.
Logo: attach [exact approved logo file/variant]. Preserve it unchanged. If the model cannot preserve the mark, leave a clean empty placement area for later compositing.
Format: [verified placement, dimensions, aspect ratio, orientation, and safe area]. If placement specs are unknown, ask or mark the canvas as an unverified concept size; do not call it print-ready.
Avoid: fake text, misspelled Arabic, invented logos, unapproved claims, extra products, unapproved colors, generic cultural shorthand, watermarks, and distinctive imitation of a named reference.
Review: verify message hierarchy, exact script, contrast, crop, brand fit, logo fidelity, and story accuracy. Label image output as concept art, not a production poster.
```

## Print and Arabic copy checks

- Verify finished size, bleed, trim, resolution, color profile, and delivery format with the actual printer before labeling a prompt or asset production-ready.
- For Arabic and bilingual layouts, state reading direction and language hierarchy, then leave editable copy space if the generator's text accuracy is uncertain. Never accept pseudo-Arabic as final text.
- Build a separate prompt for each distinct ratio or placement when the crop changes the visual hierarchy. Do not stretch one poster into every format.
- If the user only requested prompts, return the prompt and the inputs to attach; do not render, export, or save image files.
