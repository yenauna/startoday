# Reference Instructions — `banner-design`

Read this file, `../../shared-references/research-reference-standard.md`, `banner-sizes-and-styles.md`, and `campaign-poster-prompt.md` before art direction. For platform- or printer-specific specs, also check the current official source; the bundled size table is only a starting point.

**Approval gate:** After a read-only audit of supplied files, ask up to 3–6 unanswered, high-impact questions. Wait for the user to confirm the campaign brief, requested deliverable, and research scope before project-specific web/image research, prompt writing, file edits, or generation. Skip settled facts and low-stakes decorative choices.

## Ask high-impact campaign questions first

Inspect the approved brief, logo, campaign history, copy and placement. Ask only unresolved decisions that change the visual: campaign objective, one primary audience/action, exact placement and crop, approved headline/CTA/legal copy, campaign moment/offer, country/region and real-setting context, assets to attach, requested aspect ratios, number of distinct routes, and whether output is a prompt or a requested built file. Don't ask for routine decorative preferences; propose a direction grounded in the brief. Confirm the message hierarchy and copy lock before drafting.

## Research campaigns as campaigns

Inspect at least five distinct actual banner/poster/launch visual projects relevant to the channel, objective, market and format. Include the real platform/crop context when known. Record dominant focal area, reading order, image-to-copy ratio, negative space, safe placement relative to the actual crop, logo position/scale, contrast, imagery/material/light, and whether the visual supports the action. Separate composition observations from your judgment. Use no reference headline, campaign copy, or distinctive visual signature in the new prompt.

Verify current specifications from the official platform/printer before choosing final size, safe area, file format, file limit, resolution, color profile, bleed or trim. Search snippets and older size tables are not authority for volatile specs. Note checked source/date. If exact placement is unknown, ask; don't pretend a generic canvas is correct.

## Direction and prompt branches

- **Product launch** → hero product and one clear benefit/action, but only approved factual claims.
- **Awareness/story** → human/product narrative grounded in true brand context; country, people and setting need confirmation.
- **Offer/CTA** → exact approved copy and high-contrast order; do not invent discount, URL, date or legal copy.
- **Social crop family** → start with the primary placement; create separate crop-safe compositions per size instead of stretching one layout.
- **Print/poster** → verify print specs with official printer and leave production details unresolved until confirmed.
- **No locked brand or campaign copy** → ask or return to `brand-identity`; do not invent a brand or message.

Every prompt names exact logo/board/product files, spelling, copy, HEX roles, ratio, composition, hierarchy, output/crop, exclusions and quality tests. If Arabic text/logo rendering is uncertain, reserve clean areas for manual typesetting and compositing. Generate HTML/visual files only when explicitly requested. Review message comprehension at actual display scale, logo/text fidelity, crop on all placements, contrast and consistency.
