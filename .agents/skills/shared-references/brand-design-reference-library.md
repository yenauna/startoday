# Brand Design Reference Library

Research snapshot: 16 November 2026. This is a curated visual-study set of 60 identity, packaging, mockup, campaign, and guideline projects from public design portfolios and specialist case-study sources. The collection deliberately spans consumer goods, services, technology, education, health, mobility, sport, culture, real estate, and other sectors rather than treating food and hospitality as the default.

## How to use this library

- Use these projects to study design decisions, systems, and presentation structure. Do not reproduce a logo, illustration, exact layout, signature pattern, or trade dress.
- Translate a useful observation into a fresh direction that fits the client's locked brief, audience, market, and competitive context. Never treat an example's colors, fonts, or mockup set as defaults for another brand.
- Behance entries are creator-published case pages. Some explicitly describe conceptual work; others do not confirm whether the work was commissioned or launched. Treat them as visual studies, not verified commercial outcomes.
- A search result or a page that returns HTTP 403 to an automated browser is not proof that a reference is dead. Distinguish a confirmed 404 or removed page from a platform block, login wall, or temporary network failure; prefer the canonical project page and recheck it before use.
- The notes below summarize public case-page descriptions and visible project framing. Verify the source page and inspect the actual images before making a fine-grained claim about a shape, color value, or production detail.
- For each new project, record the source URL, what was observed, what should be learned, and what must stay original. Never paste an inspiration prompt into an image model as a copying instruction.

## Synthesis: patterns worth reusing as methods

### Identity and logo

- A memorable mark is more useful when its idea can generate a repeatable system: a grid, pattern, monogram, illustration family, or motion rule (WORKFLOW, Pinterest, National Packaging).
- Strong concept work anchors the symbol in a specific brand truth or object, then tests whether it still reads at favicon, label, sign, and one-color sizes (National Packaging, Aether Airlines, Pinterest).
- Bilingual work needs designed relationships between scripts: equal hierarchy when the brief calls for parity, compatible rhythm, and separate small-size legibility checks (Design Doha, Summer 24, Asli, FASILA).
- Cultural references should come from the actual audience and market; use interviews, real artifacts, language review, and local context rather than decorating with generic motifs (Asli, GAIA, The Way Home, Oud Square).

### Packaging and mockups

- Strong packaging systems make a family recognizable while allowing meaningful product-level variation (Crumble & Co., Lalalife, N&T).
- A mockup should demonstrate a plausible customer touchpoint and the actual surface, material, print method, scale, and viewing distance—not just paste a logo onto a pretty object (Noera, Aether Airlines, Khan's Mart, Geber).
- Camera, light, and material should help read the object and identity. More dramatic lifestyle imagery is a campaign choice, not a default for every guideline mockup (ONDO, VCLOR, PHASE).
- Verify logo fidelity in generated images. Use the supplied logo as a placed asset in HTML or a compositing step when exact spelling and geometry matter.

### Presentations, campaigns, and guidelines

- A case-study page should tell a sequence: positioning or idea, mark, visual language, core rules, then selected applications that prove the system (OBJET, SANDECO, Brand New Conference 2024).
- Present the brand's actual texture, contrast, rhythm, and density in the page itself; don't use the same Behance-style layout for every personality.
- Campaigns can add one seasonal or message layer while retaining the brand's recognizable type, palette, logo handling, and crop logic (N&T, SHOCKS Burger).
- Guidelines need executable rules and examples. A named motif, color, or typeface becomes useful only when the document explains where it appears and what to preserve (Garcia Creative, Rotanix, Crosstide).

### Reference-to-brief workflow

For each project, create a small precedent card with: reference name and URL; audience/market if stated; one observed principle; one element that must not be copied; the proposed translation into the new brand; and one real-size or real-surface test. Keep observed facts separate from interpretation, and mark portfolio concepts as concepts.

## Source-quality note

This set combines creator portfolios, studio case studies, and award-book examples. The portfolio pages are useful for visual range, but their self-reported project descriptions are not independent evidence of commercial impact. Use official platform documentation for changing delivery specifications and verify current production requirements before export.
