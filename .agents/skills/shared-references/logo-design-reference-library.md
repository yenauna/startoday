# Logo Design Reference Library

A curated set of **27 distinct public Behance projects** for learning methods in logo concepting, Arabic/Latin wordmarks, logo color variants, guidelines, and logo-derived patterns. The entries point to source project pages; they do not grant rights to reuse the artwork.

## Research status and use

This snapshot was assembled from direct Behance project pages and image-search previews that returned project-image descriptions. The preview notes below are **candidate visual observations**; they are not a substitute for opening the canonical page and inspecting the current image itself. In the repository-authoring pass, the embedded browser repeatedly timed out while opening Behance. Therefore, the actual page-level visual inspection status for this snapshot is **not verified**. A branding task must reopen the direct sources and visually inspect the relevant images before counting any toward its research minimum.

When a task requires research, read `visual-analysis-workflow.md` and the skill-specific research protocol. Follow the `agent-reach` skill for supported public reading, and use an image-capable browser/viewer for the actual image. Text, titles, thumbnails, and image-search-generated descriptions are discovery aids only; do not cite them as direct visual inspection. Do not bypass login, CAPTCHA, rate limits, or access controls. Never copy the project’s logo, exact letterforms, distinctive shapes, palette, layout, or pattern. Mark client/student/concept status conservatively, and do not imply commercial success unless the source proves it.

## Coverage

- **27 unique direct project pages** in this initial library snapshot.
- Mix of logo construction/guidelines, wordmarks (including Arabic and bilingual work), color variants, and logo-derived pattern systems.
- Includes Egyptian and other Arabic-market candidates as well as global projects. Verify market, client status, date, and image accessibility on the source page each time before relying on them.
- None of the entries is ranked as a model to imitate. Use each only to study one general method, then test that method against the new brand’s locked brief.
