# Arabic Brand Design Reference Library

Research snapshot: 16 November 2026. This library contains 50 Arabic-market design projects, all linked to Behance project pages. It is Egypt-led (40 Egypt-focused cases, 9 Saudi-market cases, and 1 Qatar event identity) and spans consumer goods, fashion, healthcare, finance, education, sport, travel, real estate, architecture, logistics, energy, agriculture, telecom, nonprofit, culture, and events.

## How to use this library

- Use the work to study decisions and systems, never to reproduce a logo, custom lettering, recognizable illustration, exact palette, composition, packaging trade dress, or signature graphic.
- A Behance project page confirms that a portfolio entry exists; it does not by itself prove that the work was commissioned, launched, or adopted by the named organization. Each status note is limited to what the public project framing supports.
- Search-indexed pages and pages returning HTTP 403 to an automated browser are not automatically broken. Confirm a removed page or 404 before replacing a link; identify platform blocks, login walls, and network failures separately.
- Reopen the project and visually inspect its actual images before making specific claims about color, shape, materials, hierarchy, or execution. Titles, snippets, and thumbnails are not visual inspection.
- Keep observation separate from interpretation. Translate one useful method into the new brief and name what must remain original.
- Arabic is a language and script with audience, dialect, reading-order, and legibility needs—not decorative texture. Confirm the requested language hierarchy and spelling with the client.

## Research and use notes

- For any requested visual analysis, use `visual-analysis-workflow.md`; open the direct Behance project page, inspect its actual images, and log observations separately from interpretation.
- Label concepts, unofficial redesigns, and unclear commissioning status honestly. Do not state that a reference is a current official identity unless the primary source confirms adoption.
- Use a reference to understand a design decision, then make a different decision that fits the new brand's approved brief.
- For bilingual and Arabic work, confirm spelling, dialect, script hierarchy, and small-size legibility. If image tools cannot reproduce Arabic text or the approved logo faithfully, reserve clean editable space for later typesetting/compositing.
