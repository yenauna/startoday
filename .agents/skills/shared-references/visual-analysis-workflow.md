# Visual Reference Analysis Workflow

Use this workflow for every design-facing skill, not only when the user explicitly asks for inspiration. Before acting, read the active skill's `references/reference.md` and [Research Reference Standard](research-reference-standard.md). Each skill requires **at least five distinct, relevant real projects with actual images visually inspected**. A complete `lets-brand` prompt pack that includes mockups and every direct mockup-prompting task additionally requires **five distinct, visually inspected global references and five distinct, visually inspected Arabic-market references**. Logo tasks use sources relevant to their branch (marks, wordmarks, usage guides, colors, or patterns); Arabic/bilingual work includes Arabic-script visuals. The [Logo Design Reference Library](logo-design-reference-library.md) starts with 27 project leads; its preview notes are discovery aids, and direct visual inspection is still required. The [Brand Design Reference Library](brand-design-reference-library.md) contains 60 general/global starting examples; the [Arabic Brand Design Reference Library](arabic-brand-design-reference-library.md) adds 50 projects, with an Egyptian majority.

## Research responsibly

1. For required mockup research, select candidates from both brand-design libraries, then open their direct source pages. For logo research, start with `logo-design-reference-library.md` and select sources relevant to the logo route, writing system, category, market, and application. Prefer credited case studies, studio portfolios, or official brand pages over unattributed reposts.
2. Inspect the actual identity/mockup images on each source page. A search snippet, text summary, thumbnail, title, or library description alone does not count as visual inspection or toward the 5+5 minimum.
3. Use native public search/read tools first where available; activate/follow the `agent-reach` skill for supported channels or when native access is missing or incomplete. Use an image-capable browser or visual inspection tool when image pixels/layout are not available in text output. Agent Reach is read-only; follow its channel, login, rate-limit, and platform-block rules.
4. For Arabic-market projects, identify the specific country/city, script/dialect, audience, and market from the source. Do not treat Arabic-speaking markets as one design context.
5. Record the project, credited designer/studio, direct URL, date if stated, project type, commissioned/concept/unclear status, whether the page loaded, and whether the relevant images were visually inspected.
6. Count distinct projects, not URLs or search results. De-duplicate projects repeated across sites. For a complete mockup pack, document at least five visually inspected global projects and five visually inspected Arabic-market projects. For a new-logo task, document at least five visually inspected logo projects. State counts separately by requirement and market.
7. Do not imply that a portfolio project was launched, successful, or commercially proven unless the source establishes that.
8. Do not download, embed, or redistribute artwork without an appropriate right to do so. Link the source and describe transferable principles instead of reproducing the imagery.
9. Do not sign in, bypass access controls, or make social posts, comments, follows, or other write actions. If a page is inaccessible, try a different relevant library entry. If either group remains below five, report the exact limit and do not claim a completed reference scan.

When visual access or Agent Reach is unavailable, add this exact note to `prompts.md` and keep affected prompt decisions provisional:

> NOTE: Use the Agent Reach skill to access and visually inspect the reference URLs before finalizing these prompts.

## Precedent card

For each useful example, write:

- Reference and direct source URL
- Access status: opened / inaccessible; visual inspection: yes / no
- Context: category, audience, country/region, and channel if the source states them
- Observation: what is visibly or explicitly present in the source images/page
- Interpretation: why that choice might work for its stated brief
- Transferable method: a general move that could be useful elsewhere
- Originality boundary: the named element to avoid copying
- Test: one real-size, real-material, or alternate-channel check

Keep observations and interpretations separate. If a palette, typeface, or visual detail cannot be confirmed from the source, say so instead of guessing. Do not count a text-only Agent Reach result as visual inspection.

## Review rubric

Score each dimension from 0 to 2 only when it helps the user compare examples: 0 = not demonstrated, 1 = partly demonstrated, 2 = clearly demonstrated. Add “unknown” when evidence is missing.

| Dimension | Check |
|---|---|
| Brief fit | Does the work clearly respond to a specific audience, offer, and market? |
| Distinctive idea | Can the central idea be described in one short sentence? |
| Logo craft | Is the logo idea clear, distinctive, faithful to the brief, and usable at the required scales/scripts? |
| System strength | Do the mark, type, color, imagery, and graphic devices behave like one family? |
| Touchpoint fit | Do applications match actual use rather than generic mockup conventions? |
| Adaptability | Does the identity hold across small, large, light, dark, static, and motion contexts as relevant? |
| Craft and clarity | Are hierarchy, spacing, legibility, contrast, material, and production details resolved? |
| Evidence quality | Is the work a credited project page, official case study, or an unverified/concept portfolio? |

The rubric is a discussion aid, not an objective ranking or a substitute for a client's approval.

## Translate examples into a fresh direction

Group references by the decision they demonstrate—such as letterform behavior, product-family coding, crop-safe composition, material cues, or editorial pacing. Choose at most one or two principles for the new direction. Then restate those principles without the original brand names and test them against the locked brief. Do not combine several recognizable motifs into a collage.

For Arabic and Egyptian references, confirm the target country/city, script hierarchy, language or dialect, and audience before adapting any method. Do not generalize one project's cultural motifs to another brand.

### Research summary prompt

Use only after the user has requested research. Replace every bracket from verified source pages and the locked brief; if a required brief detail is missing, ask before deciding it.

“Review [number] distinct public brand-design case studies relevant to [industry, audience, and market]. For each, record a direct URL, project context, evidence-based observation, transferable method, and originality boundary. Mark conceptual or unverified work clearly. Compare the examples by [decision areas]. Recommend [number] principles that fit the locked brief for [brand], explain why each fits, identify what must not be copied, and propose one real-world test for each. Do not lift a logo, exact palette, typeface, illustration, layout, or signature device from a reference. Separate facts from interpretation and report inaccessible or uncertain evidence.”
