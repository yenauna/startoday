# Reference Instructions — `logo-pattern`

Read this file, `../../shared-references/research-reference-standard.md`, `logo-pattern-system.md`, the approved master logo, `brand identity.txt`, and its usage rules. A pattern is a secondary identity component derived from an approved mark, never a replacement logo.

**Approval gate:** Confirm that the source logo and permitted components are approved; audit its file and rules read-only. Ask only missing decisions that change the pattern, then wait for approval of surface, allowed transformations, and research scope before project-specific reference research or prompt/file output.

## Ask only pattern decisions that matter

Confirm which product/surface, size/crop, material/process, country/region (if depicted), level of prominence, text/logo quiet zones, exact approved colors, and whether rotation/mirroring/cropping/outline/transparency are allowed. Ask which parts of the approved mark are separable. If the user hasn't approved a source logo or its component use, stop and return to `../../logo-design/SKILL.md`, `../../logo-text/SKILL.md`, or `../../logo-guidelines/SKILL.md` as appropriate.

## Research actual repeat systems

Inspect at least five distinct real project pages whose actual images show a logo-derived repeat or identity pattern. Record the source mark, derivation sequence, tile/repeat type, spacing, scale/density, pattern-to-logo hierarchy, color variants, application surface and whether the source identifies any constraints. A page titled “pattern” without an actual pattern image does not count. Learn a construction method; never copy a competitor's motif, repeat tile or signature geometry.

## Derivation decision tree

- **Whole mark repeat** → only when repeat is permitted, the mark stays recognizable and dense repetition does not make it a fake primary logo.
- **Approved symbol/subshape** → only when the owner confirms it can be separated without changing meaning.
- **Counter/negative-space module** → test for accidental new-symbol or competitor resemblance.
- **Geometric module** → derive proportions from the real vector; specify grid and mathematical tile edges.
- **Text/Arabic wordmark repeat** → preserve the exact full name unless owner approves abstraction; protect RTL joins and legibility.
- **Pattern doesn't need the logo** → ask if a broader identity graphic is intended; that is outside logo-pattern and should be directed to the identity system.
- **No approved master** → stop; do not invent a new pattern as a proxy.

## Prompt contract

Describe exact source file and authorized component; repeat type/tile dimensions; motif scale/spacing/density/direction; allowed transformations; exact colors/roles; quiet zones; seamless edges; target material and output ratio; plus a separate application prompt only if requested. Ask for a flat repeatable swatch first. Check seams, stroke consistency, crop, contrast, scale, brand recognition, and legal/production limits. If the user requests a real scene, state country/region. Don't let an image generator redraw the approved mark; use vector compositing for exactness.
